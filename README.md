# Thomas Idziak Fotografie

Statische Website für Content-Fotografie in Berlin und Brandenburg.

## Website

Die vollständige Website liegt in `index.html`. Sie benötigt keine Installation, keine externen Schriftarten und keine JavaScript-Bibliotheken. Kontakt erfolgt über einen normalen Instagram-Link. Ein Kontaktformular oder Tracking ist nicht eingebaut.

## Vorschau

`index.html` herunterladen und im Browser öffnen.

## GitHub Pages aktivieren

Im Repository unter Settings > Pages bei Build and deployment die Source „Deploy from a branch“ wählen. Branch `main` und Ordner `/ (root)` einstellen und Save klicken. GitHub zeigt danach die Website-Adresse an. Die erwartete Adresse lautet https://thomasidziak-sys.github.io/content-mit-thomas/ und ist erst nach erfolgreicher Bereitstellung erreichbar.

## Vor öffentlichem Einsatz ergänzen

- Eigene Portfoliofotos und gegebenenfalls ein eigenes Porträt einsetzen. Die derzeitigen Portfolioflächen sind ausdrücklich Platzhalter.
- Vollständiges Impressum und zur tatsächlichen Website passende Datenschutzerklärung ergänzen. Keine Adressen oder Kontaktdaten wurden erfunden.
- Den sichtbaren Entwurfshinweis erst nach Fertigstellung entfernen.
- Domain thomas-idziak-fotografie.de erst nach abgeschlossener Einrichtung von GitHub Pages verbinden. Aktuell ist keine Domainkonfiguration hinterlegt.
